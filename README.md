# Legacy Stone Care Webpage

## Local Deployment Instructions

To view your site locally, you can use a simple static server. Here are two easy options:

### Option 1: Using Python (recommended)
1. Open a terminal in this folder (`lscwebpage`).
2. Run:
   - For Python 3: `python -m http.server 8080`
3. Open your browser and go to: [http://localhost:8080](http://localhost:8080)

### Option 2: Using Node.js (if installed)
1. If you have Node.js, you can use the `http-server` package:
   - Install it (if needed): `npm install -g http-server`
   - Run: `http-server -p 8080`
2. Open your browser and go to: [http://localhost:8080](http://localhost:8080)

---

Your site will be visible at the above address. If you need help deploying to the web (Netlify, Vercel, GitHub Pages, etc.), just ask!
